TroubleshootingWhen something goes wrong?Common first-day errors ›
"python is not recognized", or the Microsoft Store opens
Reinstall Python with "Add python.exe to PATH" ticked.
A .bat window flashes and closes
Run the same command inside shell.bat so you can read the error.
"Twitch API keys missing"
Fill in the twitch: section of secrets.yaml.
Your streamer shows [OFF]
Run python -m clipfarm sources: it lists exactly what's missing.
"run: python -m clipfarm connect …"
Run that command. A permission was added, or a sign-in expired.
"Auto-post failed, retrying: …" on the review page
The text says why. Paste it to Claude if it's unclear.
Something isn't set up
Run python -m clipfarm doctor: it lists every item and the fix.
A scheduled job seems to do nothing
Read its log in data\logs.
Anything else
Copy the full message and send it to Claude. Nothing has run against the live platforms yet, so expect a few first-day fixes.
